# Spring Security Demo  

This is a simple **Spring Boot application** that demonstrates the use of **Spring Security**. It allows users to:  
- **Register** a new account  
- **Log in** with existing credentials  
- **Access protected endpoints** based on their authentication status  

The project is organized using a layered architecture:  
- **Controller** – Handles HTTP requests and responses  
- **Service** – Contains business logic  
- **Repository** – Manages database operations  
- **Model** – Defines the data structure  
- **DTO** – Transfers data between layers  
- **Config** – Sets up Spring Security  

Great for beginners learning **Spring Security** and **user authentication**!
